หนังเรื่องนั้นชื่ออะไรนะ?

เล่าสิ่งที่จำได้ — ฉากใดฉากหนึ่ง เนื้อเรื่องคร่าว ๆ หรือช่วงปีที่ดู พิมพ์ไทยหรืออังกฤษก็ได้ แล้วจะได้ชื่อเรื่อง พร้อมข้อความจากเรื่องย่อที่ใช้เป็นหลักฐาน ถ้ายังไม่แน่ใจจะบอกตรง ๆ และถามเพิ่ม
